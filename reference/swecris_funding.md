# Search the SweCRIS API for funding data

Performs a search for funding and exports results as an R object

## Usage

``` r
swecris_funding(searchstring = "KTH, Kungliga Tekniska Högskolan", token)
```

## Arguments

- searchstring:

  string to search for, Default is the search string for KTH

- token:

  token to be used for authentication

## Value

an R object with the search result

## Details

see [details about available data](https://swecris-api.vr.se/index.html)
