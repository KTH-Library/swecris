# Search the SweCRIS API for an organization

Performs a search and exports results as an R object

## Usage

``` r
swecris_search(orgs = "KTH, Kungliga tekniska högskolan")
```

## Arguments

- orgs:

  string to search for, Default: "KTH, Kungliga Tekniska Högskolan"

## Value

an R object with the search result in the form of a data frame

## Details

see [details about available data](https://swecris-api.vr.se/index.html)
